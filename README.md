# 💼 Mohith Portfolio

A modern, responsive personal portfolio website built with **HTML5**, **CSS3**, and a minimalist futuristic design. This portfolio showcases my projects, technical skills, and contact information while emphasizing clean UI, responsiveness, and performance.

---

## 📖 Overview

This portfolio is designed to present my work as a **Frontend Developer** and **AI Enthusiast**. It features a sleek dark theme, smooth navigation, project showcases, technical skills, and an easy way for visitors to connect with me.

---

## ✨ Features

- 🎨 Modern futuristic dark UI
- 📱 Fully responsive design
- 📌 Sticky navigation bar
- 🚀 Smooth scrolling navigation
- 👨‍💻 Hero section with personal introduction
- 📂 Project showcase section
- ⚡ Tech stack with animated skill bars
- 🛠️ Tools & Platforms section
- 📧 Contact section with social links
- 💻 Clean and semantic HTML5 structure
- 🎯 Lightweight with no frameworks
